# Timeline Tools — Clickable Prototype

Front-end only prototype of Timeline Tools (audio clean-up, mastering, subtitles, Audio Drama Studio) plus the Admin CMS (`#/admin/overview`).
Static HTML/CSS/JS — no build step. All data is sample data; no real processing, payments or backend. CMS edits persist in the browser's localStorage.

Open `index.html` or deploy the repo root as a static site (Vercel: framework "Other", no build command).
